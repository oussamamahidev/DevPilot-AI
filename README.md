# DevPilot AI

DevPilot AI is a secure multi-workspace agentic RAG platform for private document intelligence. The platform will let users upload private documents, process them asynchronously, embed and index chunks, ask questions, receive cited answers, store conversations, evaluate quality, and monitor the system.

This repository currently contains only the clean foundation. Business features such as authentication, document processing, RAG, agents, and evaluation will be added in later phases.

## Architecture

- **Backend:** FastAPI, Python, SQLAlchemy-ready modular structure.
- **Frontend:** Next.js, TypeScript, Tailwind CSS.
- **Database:** PostgreSQL for users, workspaces, documents, conversations, and metadata.
- **Vector database:** Qdrant for document chunk embeddings.
- **Queue:** Redis, planned for Celery background processing.
- **LLM providers:** Ollama first for local development, with optional future extension points for OpenAI and Gemini.
- **Monitoring:** structured logs first, with Prometheus and Grafana planned under `monitoring/`.
- **Deployment:** Docker Compose for local development and demonstration.

## Run With Docker Compose

Create a local environment file:

```bash
cp .env.example .env
```

Configure Ollama on the host machine before uploading documents. Document
processing uses Ollama embeddings, and the Docker containers reach Ollama at
`host.docker.internal:11434`.

If Ollama runs as a systemd service on Linux, bind it to all interfaces so
Docker can reach it:

```bash
sudo mkdir -p /etc/systemd/system/ollama.service.d
printf '[Service]\nEnvironment="OLLAMA_HOST=0.0.0.0:11434"\n' | sudo tee /etc/systemd/system/ollama.service.d/override.conf
sudo systemctl daemon-reload
sudo systemctl restart ollama
```

If you run Ollama manually instead of using systemd:

```bash
OLLAMA_HOST=0.0.0.0:11434 ollama serve
```

Pull the required embedding model:

```bash
ollama pull nomic-embed-text
curl http://localhost:11434/api/tags
```

Start the full stack:

```bash
docker compose up --build -d
```

Apply database migrations after the services are running:

```bash
docker compose exec -T backend alembic upgrade head
```

Verify that Celery can reach Ollama from inside Docker:

```bash
docker compose exec -T celery_worker python -c "import urllib.request; print(urllib.request.urlopen('http://host.docker.internal:11434/api/tags', timeout=5).read().decode())"
```

If a host port is already in use, override it before starting:

```bash
BACKEND_HOST_PORT=8001 FRONTEND_HOST_PORT=3001 FRONTEND_URL=http://localhost:3001 BACKEND_CORS_ORIGINS=http://localhost:3001 docker compose up --build -d
```

Useful URLs:

- Backend API: http://localhost:8000
- Backend health: http://localhost:8000/health
- Backend docs: http://localhost:8000/docs
- Frontend: http://localhost:3000 by default, or the value of `FRONTEND_HOST_PORT`
  in `.env` such as http://localhost:3001
- Qdrant dashboard/API: http://localhost:6335
- Redis host port: `6380` by default, mapped to `6379` inside Docker

Follow logs while testing uploads and chat:

```bash
docker compose logs -f backend celery_worker frontend
```

Stop services:

```bash
docker compose down
```

## Run Backend Locally

From the repository root:

```bash
cd backend
python -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
```

Use local service URLs if you run PostgreSQL, Redis, and Qdrant from Docker:

```bash
export DATABASE_URL="postgresql+asyncpg://devpilot:devpilot@localhost:5432/devpilot"
export REDIS_URL="redis://localhost:6380/0"
export QDRANT_URL="http://localhost:6335"
export SECRET_KEY="local-development-secret"
```

Run the API:

```bash
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

Run tests:

```bash
pytest
```

## Database Migrations

With the Docker Compose stack running, apply migrations inside the backend
container:

```bash
docker compose exec -T backend alembic upgrade head
```

If you only want to start PostgreSQL:

```bash
docker compose up -d postgres
```

When running migrations from the host with `make`, match the exposed Postgres
port from `.env`:

```bash
POSTGRES_PORT=5433 make migrate
```

Create a new autogenerated revision:

```bash
make revision message="describe schema change"
```

## Local AI With Ollama

DevPilot AI uses Ollama for local embeddings by default. If `LLM_PROVIDER=ollama`,
Ollama is also used for answer generation. OpenAI settings are optional future
configuration and are not required to start the backend.

Install and run Ollama on the host machine, then pull the local models. When
the backend runs in Docker on Linux, bind Ollama to `0.0.0.0` so the containers
can reach it through `host.docker.internal`. If Ollama is installed as a
systemd service, use the override commands in the Docker Compose section above.
If you run it manually, start it with:

```bash
OLLAMA_HOST=0.0.0.0:11434 ollama serve
```

Pull the local models:

```bash
ollama pull qwen3:8b
ollama pull nomic-embed-text
curl http://localhost:11434/api/tags
```

Recommended Ollama models for local development:

Default local setup:
- Generation: `qwen3:8b`
- Embeddings: `nomic-embed-text`

Alternative generation models:
- Generation: `qwen3:4b` for lower latency, or `qwen2.5:3b-instruct-q3_K_S` for faster development
- Embeddings: `nomic-embed-text` or `mxbai-embed-large`

Pull the default local models:

```bash
ollama pull qwen3:8b
ollama pull nomic-embed-text
```

Test generation:

```bash
curl http://localhost:11434/api/chat \
  -H "Content-Type: application/json" \
  -d '{
    "model": "qwen3:8b",
    "messages": [
      {
        "role": "user",
        "content": "Answer in one short sentence: what is RAG?"
      }
    ],
    "stream": false,
    "think": false,
    "options": {
      "temperature": 0.2,
      "num_predict": 256
    }
  }'
```

`OLLAMA_CHAT_THINK=false` is recommended for `qwen3` RAG chat so the model returns answer content directly instead of spending the token budget on thinking output.

Test embeddings:

```bash
curl http://localhost:11434/api/embed \
  -H "Content-Type: application/json" \
  -d '{
    "model": "nomic-embed-text",
    "input": "DevPilot AI is a private document intelligence platform."
  }'
```

Local-only AI configuration:

```txt
LLM_PROVIDER=ollama
EMBEDDING_PROVIDER=ollama
OLLAMA_BASE_URL=http://host.docker.internal:11434
OLLAMA_GENERATION_MODEL=qwen3:8b
OLLAMA_CHAT_THINK=false
OLLAMA_EMBEDDING_MODEL=nomic-embed-text
EMBEDDING_DIMENSION=768
GENERATION_TEMPERATURE=0.2
GENERATION_MAX_TOKENS=1000
RAG_TOP_K=5
RAG_MAX_CONTEXT_CHARS=6000
```

Check backend AI configuration without exposing secrets:

```bash
curl http://localhost:8000/api/v1/system/ai-config
curl http://localhost:8000/api/v1/system/ai-health
```
